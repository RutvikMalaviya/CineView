# Command: /implement-screen

Implement a CineView App Router page from its Stitch reference:

1. Check `DESIGN.md` for the Stitch screen ID and route mapping.
2. Inspect the Stitch screen via Stitch MCP (`get_screen`) if layout details are needed.
3. Reuse `src/components/layout/` (`Navbar`, `Footer`) and `src/components/ui/` primitives.
4. Ensure responsive desktop + mobile layout, loading/empty/error states, and keyboard accessibility.
